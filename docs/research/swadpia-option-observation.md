# 레퍼런스 관찰 — 일반지명함 상품 페이지 옵션 동작

대상: `https://www.swadpia.co.kr/goods/goods_view/CNC1000/GNC1001` (2026-11-13 관찰, **주문/장바구니 담기는 하지 않음**)

## 관찰 방법과 한계 (중요)

- 샌드박스에서 `curl`로 받은 **서버 렌더 HTML**(약 650KB)의 옵션 마크업만 분석했다.
- 헤드리스 브라우저로 옵션을 직접 눌러 보려 했으나 사이트가 헤드리스 접속을 502로 거부했고,
  브라우저로 위장하는 우회는 하지 않았다. 옵션 계산 JS(`product_class_CNC1000.min.js`,
  `print_class…`, `postpress_class…`)도 직접 요청 시 403이라 **읽지 못했다**.
- 따라서 아래 "화면 구성"은 **관찰한 사실**, "동작 추론"은 **마크업 구조와 일반적인 인쇄 주문 UX에서 추정한 것**이다.
  실제 가격 계산식·옵션 간 제약표는 확인하지 못했다 → 창운 데모는 자체 규칙으로 설계한다.

## 관찰한 사실 (HTML 구조)

옵션 패널 순서: **용지 → 인쇄도수 → 규격 → 수량 → 파일접수 방식 → 디자인비 → 후가공 → 가격 상세**

| 영역 | 관찰 내용 |
| --- | --- |
| 용지 | 용지 종류 select + 코팅 종류(무광코팅 / 유광코팅 / 코팅없음) 선택 |
| 인쇄도수 | 양면칼라, 단면칼라, 단면+금색, 양면+금색, 단면+은색, 양면+은색, 금+은 조합, 인쇄없음 (8종) |
| 규격 | "규격사이즈" 드롭다운 + "사이즈 직접입력". 직접입력 시 **재단사이즈**(가로/세로 mm)와 **작업사이즈**(재단 + 여백)가 따로 표시됨 |
| 수량 | `수량 × [1..120] 건` — 수량 select와 **건수(종류 수)** select 조합 |
| 파일접수 | 셀프 PDF / 디자인 의뢰 등 접수 방식, 별도 디자인비 행 |
| 후가공 | 별도 패널(형압: 신규/보유동판, 앞/뒤 돌출, 가로·세로 mm 입력 등). 선택한 후가공은 **미리보기 패널**에 반영 |
| 가격 | `pnl_order_price_detail` 가격 상세 패널이 옵션 영역과 분리되어 있고, 옵션 변경 시 갱신되는 구조 |
| 부가 | 교정확인 여부, 알림톡 수신 번호, 파일 메모 입력 |

## 동작 추론 (미확인)

1. 옵션이 바뀔 때마다 서버/스크립트로 재계산 → 가격 상세 패널 갱신 (페이지 이동 없음).
2. 용지가 바뀌면 코팅·평량·인쇄도수 선택지가 그 용지에서 가능한 것으로 다시 채워짐.
3. 규격을 직접 입력하면 재단/작업 사이즈가 갱신되고 허용 범위를 벗어나면 경고.
4. 후가공을 선택하면 추가 입력(위치·크기)이 열리고 미리보기와 가격에 반영됨.
5. 가격과 함께 출고 예정일이 표시되는 것이 일반적 (후가공이 있으면 지연).

## 창운 데모에 가져올 것 (구조·동작만)

- 옵션을 위에서 아래로 순서대로 선택하는 패널 + **우측 sticky 가격 패널** 분리
- 용지 → (가능한 사이즈 / 후가공) 의존, 불가능한 조합은 **비활성 + 사유 표시**
- 수량 × 건수 조합
- 후가공 선택 시 가격·출고일 즉시 반영, 선택을 바꾸면 기존에 불가능해진 값은 자동으로 가장 가까운 유효값으로 보정
- 로고·이미지·문구·브랜드 색은 사용하지 않음
